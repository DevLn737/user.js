# Минимальный Firefox

Небольшой `user.js` для Firefox Release: компактный интерфейс, пустые страницы при запуске и открытии вкладки, без Firefox Sync и встроенного сохранения паролей. Остальные настройки остаются стандартными. Конфиг не предназначен для комплексного усиления защиты и не обещает отключения всех сетевых запросов или телеметрии расширений.

## Что настраивается

| Группа | Результат |
| --- | --- |
| Интерфейс | Компактная плотность, скрытая панель закладок, боковая панель скрывается после закрытия |
| Запуск | Пустая стартовая страница, без автоматического восстановления предыдущих вкладок |
| Новая вкладка | Пустая страница вместо Firefox Home |
| Учётные записи | Отключён интерфейс Firefox Sync; браузер не предлагает сохранять пароли |
| Отправка данных | Отключены отправка данных Firefox через указанные параметры и участие в исследованиях |
| Приватность | Включён сигнал Global Privacy Control; отключён сбор контекста для рекомендаций дополнений через `browser.discovery.enabled` |

Обновления браузера и расширений, встроенная защита, проверка сертификатов и штатная работа cookies сохраняются. Global Privacy Control — сигнал сайтам, а не самостоятельный блокировщик.

## Установка

1. Используйте Firefox Release. В `about:profiles` создайте профиль `minimal`, если начинаете с чистой настройки. Создание профиля не означает подключение к Mozilla или Sync: локальный профиль нужен самому Firefox.
2. Узнайте путь к **корневой папке** нужного профиля через `about:profiles` или `about:support`.
3. Полностью закройте Firefox, включая окна других профилей, и дождитесь завершения процессов.
4. Скопируйте `user.js` из этого репозитория в корневую папку профиля.
5. Запустите нужный профиль и проверьте результат. Сделайте его профилем по умолчанию.

Firefox читает файл при запуске. Автоматического скачивания изменений с GitHub нет: для обновления нужно заменить локальный файл при закрытом браузере.

**Удаление строки из `user.js` или самого файла не сбрасывает ранее применённое значение.** При обновлении старого профиля удалённые переопределения нужно отдельно сбросить в `about:config`; новый профиль не наследует эти настройки.

## Расширения

Установите только шесть расширений из официального каталога Firefox:

- **uBlock Origin** — стандартные настройки и списки фильтров.
- **Bitwarden** — подключение к своему серверу Vaultwarden; адрес и авторизацию вводите самостоятельно. Firefox Sync для этого не нужен.
- **SponsorBlock** — стандартные настройки пропуска интеграций.
- **Unhook** — скрыть главную ленту, Shorts, боковые рекомендации и рекомендации после видео; сохранить поиск, подписки и комментарии.
- **VOT — Voice Over Translation** — перевод видео по запросу, без автоматического запуска.
- **Tampermonkey** — существующие пользовательские скрипты, их настройки и сохранённые данные.

`user.js` не устанавливает расширения и не управляет их внутренними настройками. Не копируйте настройки остальных расширений из старого профиля.

## Внешний вид

Используйте встроенную системную тему и горизонтальные вкладки. Закройте боковую панель. В настройке панели инструментов оставьте навигацию, адресную строку, загрузки, меню расширений, uBlock Origin и Bitwarden. SponsorBlock, Unhook, VOT и Tampermonkey не закрепляйте на панели. Пользовательские CSS-файлы не нужны.

## Перенос Tampermonkey

1. В старом профиле откройте панель управления Tampermonkey → **Utilities / Утилиты**.
2. Экспортируйте резервную копию в ZIP или JSON-файл. Включите настройки и сохранённые данные скриптов, если экспорт предлагает соответствующие параметры.
3. Убедитесь, что копия содержит все скрипты, их настройки, значения хранилища и состояния включения. При неполной копии не удаляйте старый профиль.
4. В новом профиле установите Tampermonkey и импортируйте файл через ту же вкладку Utilities.
5. Сверьте список и состояния скриптов, настройки и значения; проверьте используемые скрипты на соответствующих сайтах.
6. Временный экспорт удалите только после успешной проверки переноса.

Экспорт может содержать приватный код, адреса и токены. Храните его локально **вне этого репозитория**; не добавляйте в Git, Issues или Pull Requests. Официальная инструкция: [Tampermonkey FAQ Q106](https://www.tampermonkey.net/faq.php?locale=en&q=Q106).

## Сохранение входов на сайты

При переходе можно отдельно перенести cookies и необходимые данные сайтов, сохраняя обычную работу истории и cookies после перехода. Выполняйте копирование при полностью закрытом Firefox; исходный и новый профиль должны использовать совместимую версию браузера. Не переносите целиком `prefs.js`, историю, браузерные пароли или хранилища ненужных расширений.

Cookies сами по себе не гарантируют сохранение всех входов: сайты могут дополнительно использовать localStorage/IndexedDB, а сервер вправе запросить повторную авторизацию. Старый профиль удаляйте только после проверки нужных входов, Tampermonkey и подключения Bitwarden.

## Проверка

После повторного запуска проверьте пустую новую вкладку, компактность и отсутствие лишних панелей, ровно шесть расширений, работу сайтов, загрузок, видео, функций YouTube, Tampermonkey и Bitwarden. Убедитесь, что Firefox не подключён к Sync и не предлагает сохранять пароли.

Приватные файлы профиля, cookies, экспорты скриптов, адрес Vaultwarden и учётные данные не должны попадать в этот репозиторий.
